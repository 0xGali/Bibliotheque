## Développement - Démarrage du projet

### Lancer l'application
1. Démarrer Docker Desktop sur votre ordinateur.
2. Dans un terminal, aller dans le dossier où se situe se fichier
3. Lancer la commande `docker compose up -d --build` et attendre que la commande ait fini de s'exécuter : le container devrait être lancé.
4. Ouvrir puis exécuter le ficher `.\applicatif\bibliothequeApp\src\main\java\com\miage\bibliothequeApp\BibliothequeAppApplication.java` (bouton Play VSCode) et attendre que l'application se lance.
5. Ouvrir puis exécuter le ficher `.\applicatif\bibliothequeWebapp\src\main\java\com\miage\bibliothequeApp\BibliothequeWebappApplication.java` (bouton Play VSCode)
6. Ouvrir l'interface web à l'adresse `localhost:9001`
