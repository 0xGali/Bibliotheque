## Développement - Démarrage du projet

JAVA Version 21
Spring Boot Version 

### Lancer l'application
1. Démarrer Docker Desktop sur votre ordinateur.
2. Dans un terminal, aller dans le dossier où se situe se fichier
3. Lancer la commande `docker compose up -d --build` et attendre que la commande ait fini de s'exécuter : le container devrait être lancé.
4. Ouvrir un terminal puis exécuter la commande `java -jar BalloirBleekerBbtqWebapp.jar` et attendre que l'application se lance.
5. Ouvrir un autre terminal puis exécuter la commande `` et attendre que l'application se lance.
6. Ouvrir l'interface web à l'adresse `localhost:9001`
